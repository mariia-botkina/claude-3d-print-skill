# Bambu Studio project (3MF) with make_3mf.py

`scripts/make_3mf.py spec.json -o Project.3mf` writes a Bambu Studio project: objects
on named plates, laid out, P1S printer + process preset, AMS filament slots with colours,
project-wide and per-object setting overrides, multi-part (multi-colour) objects and
modifiers, pauses and colour changes by height, plate thumbnails. The owner opens it, checks, and slices.

`"nozzle": 0.2 | 0.4 | 0.6 | 0.8` in the spec selects the matching P1S printer preset, its
default process and the filament variants for that nozzle (bundled in
`assets/bambu/nozzle_<d>/`). `--example` prints a full spec; `--list-filaments PLA
--nozzle 0.2` / `--list-processes --nozzle 0.2` list presets for a nozzle.
The full spec format is in the script's docstring.

## Things to settle with the owner before building the 3MF

- Which filament is in which AMS slot (and colour hex if she cares about the preview).
- Plate grouping and names.
- Supports: none / tree auto / only on build plate / per object.
- Brim for small-contact parts.
- Plate type (record it in printer-profile.md once known).

## Commonly used setting keys

Project-wide ("settings") or per object ("settings" inside an object). Values may be
numbers or strings; percentages as strings ("20%").

| Key | Meaning | Typical |
|---|---|---|
| wall_loops | number of walls | 2 (default), 3-4 for strength |
| sparse_infill_density | infill | "15%" default, "20-25%" loaded parts |
| sparse_infill_pattern | infill pattern | "grid", "gyroid", "cubic" |
| top_shell_layers / bottom_shell_layers | solid skins | 5 / 3 |
| enable_support | supports on/off | 0 / 1 |
| support_type | support style | "tree(auto)", "normal(auto)" |
| support_on_build_plate_only | no supports on the model | 0 / 1 |
| support_threshold_angle | auto-support angle | 30 (Bambu's default, measured from horizontal) |
| brim_type | brim | "auto_brim", "outer_only", "no_brim", "brim_ears" |
| brim_width | brim width mm | 5 |
| seam_position | seam | "aligned", "back", "nearest", "random" |
| ironing_type | ironing top surfaces | "no ironing", "top", "topmost" |
| enable_prime_tower | prime tower | auto-on for multi-filament plates |
| print_sequence | "by layer" / "by object" | "by layer" |
| curr_bed_type (top-level "bed_type") | plate | "Textured PEI Plate", "Cool Plate", "Engineering Plate", "High Temp Plate" |
| layer height | choose a process preset instead ("process") | "0.12mm Fine @BBL X1C", "0.16mm Optimal @BBL X1C", "0.20mm Standard @BBL X1C", "0.24mm Draft @BBL X1C" |

Per-filament overrides go into the filament entry: `{"preset": "Bambu PETG HF", "color":
"#3366FF", "settings": {"nozzle_temperature": 250}}`.

## Layer events: pauses and colour changes by height

Per plate, `"events"`: a list of
- `{"type": "pause", "z": 4.2, "note": "10x3 magnet, N up"}`
- `{"type": "filament", "z": 8.0, "filament": 2}` (from 8 mm up, AMS slot 2)

`z` is a height on the part. The event happens before the first layer whose mid-plane is
at or above z (slicers cut layers at mid-height), on the grid of the chosen process
preset. For a pocket ceiling this is exactly the layer that would close it;
`find_pockets.py` prints these layers. `print_z` instead of `z` sets an exact Bambu layer
top. The script prints every event with its layer number: put that in the report.

Pauses: the project's pause G-code retracts 0.8 mm, lifts the nozzle (10 mm, less near
the top of the build volume), parks the head at X65 Y245 (back left, Bambu's own
filament-change spot), waits with `M400 U1` (resume on the printer screen or in the
app), then unretracts; the next travel move restores the height. Change the park
position with `"pause_park": {"x": .., "y": .., "lift": ..}` at the top level. Bambu
Studio shows the printer preset as modified because of this G-code: expected.

Colour changes switch the AMS slot for the whole plate from that layer on, so a plate
with colour changes may only hold objects that each use a single filament. Preview with
`render.py --bands`; the plate thumbnails show the bands too.

## Not covered (tell the owner to do it in Bambu Studio)

- Painted colour regions, painted supports/seams.
- Calibrated flush volumes: the script writes a flat 280 mm3 per change; she can press
  "Auto-calc" in the flushing dialog.

## Names

Bambu Studio refuses names containing `< > : / \ | ? * "` ("Invalid name" on opening).
make_3mf.py replaces them in the project title, plate names and object/part names
(`:` becomes ` -`); prefer names without them in the spec anyway.

## Checking the result

- The script prints plates, objects and filaments; read it.
- `unzip -l Project.3mf` shows the structure; `Metadata/project_settings.config` is JSON.
- `make_3mf.py --verify Project.3mf` runs the structural self-check (also run
  automatically after building).
- The 3MF is built from Bambu Studio's own P1S presets (assets/bambu/, regenerated by
  tools/build_bambu_profiles.py) and carries only the settings keys Bambu Studio writes
  itself; it opens with the system printer, process and filament presets (checked in
  Bambu Studio 2.06). A "Customized Preset" dialog on opening means the settings did not
  load: ask the owner for the exact message and fix make_3mf.py accordingly.
